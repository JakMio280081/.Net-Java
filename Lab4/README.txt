Funkcjonalności:
modyfikacja komponentu Weather:
prognoza pogody dla 10 dni,
licznik ciepłych dni (>15°C),
filtrowanie ciepłych dni,
filtrowanie po nazwie opisu pogody,
przywracanie pełnej tabeli,
analiza nastroju tekstu:
klasyfikacja opinii przy użyciu ML.NET,
wyświetlanie etykiety predykcji,
prezentacja poziomu pewności modelu,
interaktywny interfejs użytkownika w Blazor.

Technologie:
ASP.NET Core Blazor
.NET 8
ML.NET
Razor Components
Bootstrap
